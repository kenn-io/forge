Kenn Forge

The agent workspace that syncs with your code forge.

Kenn Forge runs coding agents in isolated worktree workspaces — and keeps every pull request, issue, and discussion from GitHub, GitLab, Forgejo, and Gitea synced into SQLite on your machine. Queues, diffs, and history open instantly from local data, with no page loads between you and the next decision. Triage, delegate, review, and merge from one console.

Linux, macOS, and Windows · single binary · bring your own agents · your forge stays the source of truth

Built to close the loop. From overnight activity to merged pull request:

  1. What changed overnight?Comments, reviews, commits, and state changes across every repository, synced locally.
  2. What can I hand to an agent?One action creates a worktree workspace from a pull request or issue and launches the agent.
  3. How are my agents doing?Durable tmux sessions with lifecycle status — active work, approval requests, input requests.
  4. What can I review and merge?Full pull request detail with CI, branch state, changed files, and provider actions.

What's inside

Agent workspaces, isolated by worktree

Every workspace is a Git worktree with durable tmux sessions. Launch shells or coding agents in one step, run them in parallel, and pick any session back up later.

The missing forge sync

Pull requests, issues, and activity from GitHub, GitLab, Forgejo, and Gitea sync into SQLite on your machine. The whole backlog reads at local speed — no browser tabs, no spinners, no waiting on the forge's web UI.

Pull requests, end to end

Description, discussion, CI, branch state, and changed files together. Review line by line, comment, approve, and merge — with stacked branches detected and ordered.

Federated workspaces

Connect Forge daemons into a hub-and-spoke fleet over authenticated HTTPS. The hub syncs your forges once and shows every workspace across your machines; each spoke keeps its agents, worktrees, and sessions local.

Local-first, by construction

One binary serves the UI and owns the data on your machine. Works offline, private by default, no hosted service in the loop — your forge stays the source of truth.

Beyond the queue

Browse repository source with file history, follow Roborev review jobs, link Kata tasks, edit local Markdown docs, and give your agents the console over MCP.
